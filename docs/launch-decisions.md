# 미정 규칙 확정 및 미니게임 출시

2026-09-07 사용자가 미정 사항의 결정을 위임하고 기존에 보류한 미니게임도 추가하도록 요청했다. 이 문서는 Notion 원문의 수치를 대체하지 않으며, 공백에 대한 제품 결정을 확정한다.

## 은행

- 대출은 차수별 발급부터 7일 만기. 초기 1주 단위 신용 조건과 맞추고 고금리 부채를 무기한 누적시키지 않는다.
- 기존 NULL 만기는 발급일+7일과 migration 적용일+7일 중 늦은 시각으로 보정해 소급 연체를 방지한다. 이미 정해진 만기는 바꾸지 않는다.
- 1/3등급은 만기 초과, 2등급은 만기+3일 초과 시 기존 공통 신용 판정으로 강등한다. 정확히 만기인 시각에는 연체가 아니다.

## 아이템과 상점

| 아이템 | 가격 | 효과 |
|---|---:|---|
| 천재 해커의 해킹툴 | 10,000,000 | 신용 한 단계 상승 시도. 이미 신용1이면 5,000,000에 아이템 보너스를 적용한 금액 지급 |
| 긍정메타 | 2,000,000 | 매도 손실 15% 완화 × 등급 보너스 × 신용 효과 |
| 정보의 왕 | 3,000,000 | 매도 이익 10% 추가 × 등급 보너스 × 신용 효과 |

구매 등급은 Notion의 AWKWARD~EPIC 확률표를 그대로 사용한다. 패시브는 영구·최고 효과 하나 적용이며 강화할 수 있다. 해킹툴은 1회 소모하며 강화할 수 없다. 획득 가능한 최고 EPIC 해킹툴의 지급액 5,750,000은 구매가보다 낮아 구매/사용으로 현금을 늘릴 수 없다.

정수 신용 상승에 50% 효과를 적용하는 방식은 **성공 확률**로 확정한다. 확률은 `min(100%, (100% + 등급 보너스) × 신용 효과)`다. COMMON 신용2는 100%, AWKWARD 신용2는 95%, COMMON 신용3은 50%다. 시도 실패도 사용 횟수를 소비한다. 신용4는 사용 자체를 거부해 아이템을 보존한다. 신용1 현금 지급에는 기존 금액 배율/버림을 사용한다.

## 미니게임과 드롭

- 신규 미니게임에는 도박세·도박 한도·퀵패스를 적용하지 않으며 도박 이력을 남기지 않는다. 모든 신용등급이 참여할 수 있다.
- 신용1은 드롭 확률에 +10%p, 신용2는 +5%p. 획득 아이템의 등급 분포는 Notion 확률표 그대로다.
- 성공한 게임만 한 번 추첨한다. 오답·시간 초과·중지·홀짝·슬롯에는 드롭이 없다. 아이템은 출시된 패시브 중 균등 추첨하며 현금성 해킹툴은 상점에서만 구매한다.
- 신규 미니게임은 오답/만료/중지 시 지갑 차감이 없다. 중지·파산·탈퇴 후에도 시작 기준 5분 쿨타임은 유지한다. 종료된 세션은 다시 정산할 수 없다.
- 기억게임은 Discord 메시지를 수정하여 숫자를 숨긴다. 화면 촬영·외부 메모 방지까지 보장하지 않으며, 반복 보상은 서버 쿨타임으로 제한한다.
- 새 게임은 베팅금이나 외부 API 없이 실행 가능하다. 기존 넌센스의 AI 키 설정은 유지한다.
